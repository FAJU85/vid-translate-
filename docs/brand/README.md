# KAVOX approved brand assets

The originals, as approved. Everything the product uses is made from these:

| File | What | Used for |
|---|---|---|
| `kavox-icon-transparent.png` | The icon, transparent | `web/public/assets/kavox-icon.png` (default logo, tab icon, page headers, admin), `favicon-64.png`, the share picture |
| `kavox-wordmark-transparent.png` | The wordmark, transparent | `web/public/assets/kavox-wordmark.png` (header next to the icon while the site is called KAVOX), the share picture |
| `kavox-icon-dark.webp` | The icon on dark navy | App icons (`icons/icon-*`, `maskable-*` with the safe margin, `apple-touch-icon`), `docs/launch/thumbnail.png` |
| `kavox-wordmark-dark.webp` | The wordmark on dark navy | Kept for print and banners |

`web/public/assets/og-image.png` (1200×630) is the picture apps show for a shared link to the
site, a landing page, or a video or profile without its own still. A logo uploaded on
/admin → Settings still replaces the icon on the site; a different site name replaces the wordmark.
